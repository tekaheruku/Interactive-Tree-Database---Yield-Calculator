1. INTRODUCTION
================================================================================================

1.1 What the program does
-------------------------
The Interactive Tree Database & Yield Calculator is a desktop program for farmers, agriculture
students, extension workers and planners. It keeps a database of tree species and, for any
species and number of trees, calculates the expected yearly harvest and the estimated gross
sales in Philippine pesos.

With the program you can:

  - filter the species by type: All Species, Fruit-Bearing or Non-Fruit-Bearing;
  - choose a species and a tree count and see the annual yield and gross sales immediately;
  - search, sort and inspect every species record;
  - see a year-by-year projection (1 to 30 years) with a chart and a table;
  - save calculations as scenarios and load them again later;
  - export a calculation to a CSV file for Excel, or print a one-page report;
  - as an administrator, add, edit and delete species records and review an audit log.

------------------------------

  Every user                  | 2 to 9, 11 and 14
  Administrator (keeps the    | 10 and 13, plus the sections above

1.3 About the figures
---------------------
  | NOTE: The 22 sample species and their yields and prices are planning estimates prepared
  | for this school project. Real yields depend on variety, tree age, spacing, soil, weather
  | and care, and farm-gate prices change with the season and the market. Check current
  | figures with the Department of Agriculture (DA), the Philippine Statistics Authority (PSA)
  | or local buyers. An administrator can update any record (Section 10).

1.4 Conventions used in this manual
-----------------------------------
  - Names of buttons, labels and windows are written in bold, for example Save Scenario.
  - Keys and shortcuts look like Ctrl+S; file and folder names look like TreeYieldDb.mdb.
  - Amounts are shown in the program with the peso sign; this manual writes them as PHP.

3. INSTALLING AND STARTING THE PROGRAM
================================================================================================

3.1 The project folder
----------------------
Copy the whole project folder to the PC (for example to the Desktop or Documents). The parts you
need are:

  File or folder                           | What it is
  -----------------------------------------+-----------------------------------------------------
  Interactive Tree Database\Interactive    | The Visual Studio solution. Open this file.
  Tree Database.sln                        |
  Interactive Tree Database\Interactive    | The Microsoft Access database with all records.
  Tree Database\Database\TreeYieldDb.mdb   |
  docs\                                    | This manual, the test cases and the source-code soft
                                           | copy.

3.2 Start the program from Visual Studio
----------------------------------------
  1. Open the file Interactive Tree Database\Interactive Tree Database.sln in Visual Studio
     2015.
  2. Press F5 (or click Start). The project Interactive Tree Database starts.

3.3 Start the program without Visual Studio
-------------------------------------------
Double-click Interactive Tree Database.exe in the folder Interactive Tree Database\Interactive
Tree Database\bin\Debug (or bin\Release). Keep the files TreeYield.Core.dll and Interactive Tree
Database.exe.config in the same folder. The program finds the database in the project folder
automatically.

To use the program on another PC without the project, copy the bin\Debug folder and put a folder
named Database with TreeYieldDb.mdb inside it, next to the .exe. (If no database is found, the
program creates a new one.)

3.4 The first start
-------------------
When the program starts, the status bar at the bottom shows "Opening the database..." and then
"Ready". If the file Database\TreeYieldDb.mdb does not exist yet, the program creates it by
itself with all tables, relationships and 22 sample species. This takes only a few seconds. The
status bar shows the name of the database file; point at it to see the full path.

If the database cannot be opened, the window Database Not Available explains how to fix it (see
Section 14).

5. CALCULATING YIELD AND SALES
================================================================================================

  1. (Optional) Click a category chip to narrow the list, for example Fruit-Bearing.
  2. Choose the species in Target Crop / Tree Species.
  3. Set the number of trees: drag the slider, click a point on it, or use the arrow keys; or
     type a number from 1 to 100,000 in the box and press Enter.
  4. Read the three result cards. They change immediately whenever you change the species or the
     tree count.

  Card                       | Meaning
  ---------------------------+-------------------------------------------------------------------
  Active Species             | The species being calculated, with its category and product.
  Annual Yield               | Tree count x yield per tree per year, at full production (mature
                             | trees).
  Estimated Gross Sales      | Annual yield x farm-gate price per unit, in pesos, before any
                             | costs.

  Worked example:
    25 Carabao Mango trees x 300 kg per tree = 7,500 kg per year
    7,500 kg x PHP 80 per kg = PHP 600,000 per year

  | NOTE: Timber trees (harvest type "Rotation", for example Mahogany or Gmelina) are cut only
  | once, at rotation age. For them the cards show annualized figures - the average per year -
  | and the caption tells you the one-time harvest value and the harvest year. Use the
  | projection (Section 7) to see when the money actually comes in.

Numbers outside the allowed range are corrected automatically: 0 becomes 1 and anything above
100,000 becomes 100,000. Letters cannot be typed in the number box.

6.1 Search
----------
  - Type part of a common name, scientific name or product in the search box (Ctrl+F jumps

move with the arrow keys) to load that species into the calculator.

6.3 Inspect a record
--------------------
Double-click a row, or select it and press Enter, to open the Species Details window with every
field of the record and the result for the current tree count. Click Use in Calculator or Close.

  [Screenshot: docs\screenshots\08-species-details.png - Figure 3. The Species Details window]

  Column                      | Meaning
  ----------------------------+------------------------------------------------------------------
  Species / Scientific Name   | Common (local) name and botanical name.
  Category / Product          | Fruit-Bearing or Non-Fruit-Bearing; what is sold (fresh fruit,
                              | timber, latex...).
  Yield / Tree / Yr, Unit     | Harvest of one mature tree per year (timber: average growth per
                              | year).
  Price / Unit                | Estimated farm-gate price in pesos for one unit.
  Harvest From (Yr)           | Annual species: first harvest year. Rotation species: rotation
                              | age.
  Harvest                     | "Annual" (harvested every year) or "Rotation" (cut once).

7. MULTI-YEAR PROJECTION
================================================================================================

Click 10-Year Projection to see what the trees produce in each year after planting.

  [Screenshot: docs\screenshots\05-projection.png - Figure 4. 10-year projection for 25 Carabao Mango trees]

  - Projection horizon (years): choose 1 to 30 years (default 10). The section name changes, for
    example "20-Year Projection".
  - Summary line: total yield and total gross sales over the horizon.
  - Chart: gross sales per year. Point at a column to see the exact amount.
  - Table: Year, Production, Yield, Gross Sales and Cumulative (running total) sales.

  "Production" shows         | Meaning
  ---------------------------+-------------------------------------------------------------------
  Not bearing yet            | The trees are still too young to harvest.
  16.7%, 50%, 100%...        | Share of full production reached that year (yield rises evenly
                             | until full production).
  Growing                    | Timber species before rotation age: no income yet.
  Harvest                    | Timber species at rotation age: the trees are cut and sold.

If the first harvest comes after the last projected year (for example Mahogany, cut at year 25),
the summary says so and shows the expected harvest value.

10. ADMINISTRATOR GUIDE
================================================================================================

Everybody can view and calculate. Only a signed-in administrator can add, edit or delete species
records.

10.1 Sign in
------------
  1. Click Admin Login.
  2. Type the username and password and click Sign In (or press Enter).

  Default account             | Value
  ----------------------------+------------------------------------------------------------------
  Username                    | admin
  Password                    | Admin@123 (works only until it is changed at the first sign-in)

  [Screenshot: docs\screenshots\11-login-error.png - Figure 8. Sign-in window after a wrong password]

  - A wrong username or password shows "Invalid username or password." For security the program
    does not say which of the two is wrong.

-----------------------------------------------
The first time you sign in with the default password, the Change Password window appears. Type
the current password (Admin@123) and a new password twice. Clicking Sign Out cancels and signs

  [Screenshot: docs\screenshots\12-change-password.png - Figure 9. The password must be changed at the first sign-in]

Password rules: at least 8 characters, with at least one letter and one number; not the same as
the username; not the default password. Write the new password down in a safe place.

--------------------------------------
  [Screenshot: docs\screenshots\13-admin-species.png - Figure 10. Manage Species Records]

  - Add Species (Ctrl+N), Edit, Delete, Refresh (F5).

  2. Fill in the fields (see the table below). The green Preview line shows what one tree is

  [Screenshot: docs\screenshots\14-editor-validation.png - Figure 11. Required fields are marked when Save is clicked on an empty form]

  Field                         | Rules and tips
  ------------------------------+----------------------------------------------------------------

  Product *                     | What is sold. Pick from the list or type your own (up to 60

---------------------

--------------
Click Audit Log to see the 200 most recent actions, newest first: sign-ins, failed sign-ins,
lockouts, password changes and every added, edited or deleted record, with time and details.

  [Screenshot: docs\screenshots\16-admin-audit-log.png - Figure 12. The audit log]

  - Change Password: type the current password and the new one twice.
  - Reset Sample Data: deletes all species (including your own) and all saved scenarios, then
    restores the 22 sample species. User accounts and the audit log are kept. You are asked to
    confirm first.
  - Sign Out: ends the administrator session. The program also signs you out automatically after
    15 minutes without administrator activity.

12. HOW THE CALCULATIONS WORK
================================================================================================

12.1 Yearly yield and gross sales
---------------------------------
  Formulas:
    Annual yield = number of trees x yield per tree per year
    Estimated gross sales = annual yield x price per unit

All amounts are calculated with exact decimal numbers, so there are no rounding errors. Pesos
are rounded to the nearest whole peso only when they are displayed.

12.2 Projection for annual species
----------------------------------
Young trees produce nothing until the first harvest year. From then on, yield rises in equal
steps until the year of full production, and stays at full production afterwards:

  Production factor in year y:
    before the first harvest year: 0%
    from the first harvest to full production: (y - first + 1) / (full - first + 1)
    from the full-production year on: 100%

Example - Carabao Mango (first harvest year 5, full production year 10), 25 trees: years 1-4
give nothing; year 5 gives 1/6 = 16.7% of 7,500 kg = 1,250 kg = PHP 100,000; year 10 gives the
full 7,500 kg = PHP 600,000. The 10-year total is 26,250 kg = PHP 2,100,000.

12.3 Projection for rotation (timber) species
---------------------------------------------
Timber grows every year but is sold only when it is cut at rotation age. The yearly yield
entered for these species is the mean annual increment (average growth per tree per year).

  Timber harvest:
    Harvest at rotation age = trees x yearly growth x rotation age
    Example - 25 Gmelina trees, 15 board ft per year, cut at year 10:
    25 x 15 x 10 = 3,750 board ft x PHP 35 = PHP 131,250 in year 10

The projection assumes the land is replanted right after a harvest, so the harvest repeats every
rotation (for Gmelina in years 10, 20 and 30).

12.4 What the program does not include
--------------------------------------
Gross sales are before costs (seedlings, fertilizer, labor, transport) and taxes. Losses from
typhoons, pests or tree deaths are not included. Use the results for planning and comparison,
not as a guarantee.

13. THE DATABASE FILE (MICROSOFT ACCESS)
================================================================================================

All records are stored in one Microsoft Access file:

  Location:
    Interactive Tree Database\Interactive Tree Database\Database\TreeYieldDb.mdb

13.1 Open it in Microsoft Access
--------------------------------
  1. Close the program first, so you do not change the same record in two places at once.
  2. Double-click TreeYieldDb.mdb, or start Access and choose File > Open > Browse.
  3. If Access shows a yellow security bar, you can ignore it; it is only needed for macros, and
     this file has none.
  4. Double-click a table in the navigation pane on the left to see its records.
  5. Choose Database Tools > Relationships to see how the tables are connected.

  Table                  | What it holds
  -----------------------+-----------------------------------------------------------------------
  Categories             | The two categories: Fruit-Bearing and Non-Fruit-Bearing.
  TreeSpecies            | One row per species: names, category, product, yield, price, harvest
                         | type and years.
  Scenarios              | Saved calculations (species, tree count, horizon, name, notes).
  Users                  | Administrator accounts. Passwords are stored only as a salted PBKDF2
                         | hash, never as text.
  AuditLog               | History of sign-ins and changes.
  SchemaVersion          | The version of the table layout (used by the program).

13.2 Rules kept by the database
-------------------------------
  - Primary keys (AutoNumber ID columns) identify every row.
  - Relationships with referential integrity: a species must belong to an existing category; a
    scenario must belong to an existing species. Deleting a species also deletes its scenarios
    (*Cascade Delete Related Records*).
  - Validation rules: for example the yield must be greater than 0, prices cannot be negative
    and full production cannot come before the first harvest. They apply even when a record is
    typed directly into Access.
  - Unique indexes: two species cannot have the same common name; two users cannot have the same
    username.

  | NOTE: Do not change the PasswordHash, PasswordSalt or Iterations columns by hand; the
  | account would no longer be able to sign in. Do not open the file with Open Exclusive while
  | the program is running.

13.3 Back up, restore and start fresh
-------------------------------------
  - Back up: close the program and copy TreeYieldDb.mdb to a safe place.
  - Restore: close the program and copy the backup back over TreeYieldDb.mdb.
  - Start fresh: close the program and delete (or rename) TreeYieldDb.mdb. The next start
    creates a new file with the 22 sample species and the default admin account.
  - Keep it small: after many changes, use Database Tools > Compact and Repair Database in
    Access.

================================================================================================
15. GLOSSARY
================================================================================================

  Term                        | Meaning
  ----------------------------+------------------------------------------------------------------
  Annual species              | A tree harvested every year once it bears (fruit, nuts, beans,
                              | latex).
  Rotation species            | A tree cut once when it reaches rotation age (timber, pulpwood).
  Rotation age                | The age, in years, at which a timber tree is harvested.
  Mean annual increment       | Average growth of a timber tree per year; harvest = increment x
                              | rotation age.
  Board foot (board ft)       | Unit of lumber volume: 1 ft x 1 ft x 1 inch.
  Farm-gate price             | Price the farmer receives at the farm, before transport and
                              | trader margins.
  Full production             | The year from which a tree gives its full yearly harvest.
  Gross sales                 | Yield x price, before costs.
  Projection horizon          | Number of years shown in the projection (1-30).
  Scenario                    | A saved calculation (species, tree count, horizon) with a name.
  Audit log                   | A record of administrator sign-ins and changes.
  Microsoft Access database   | A single file that holds tables, relationships and rules; it can
  (.mdb)                      | be opened in Microsoft Access.
  Jet OLE DB provider         | The part of Windows the program uses to read and write the .mdb
                              | file.
