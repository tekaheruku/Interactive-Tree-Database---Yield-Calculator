HOW TO USE THIS SHEET
- Start from a fresh database (see the Before You Start notes below) so the record counts match.
- Do the steps in order; some cases use data created by earlier cases.
- Mark each case PASS or FAIL. Write any difference you see under "Notes".
- TC-25 (account lockout) locks the admin account for 5 minutes, so run it last or plan for the wait.

BEFORE YOU START
- Fresh database: close the program and Microsoft Access, then delete (or rename, to keep a
  backup) the file
      Interactive Tree Database\Interactive Tree Database\Database\TreeYieldDb.mdb
  The program re-creates it on the next start with 22 sample species and the default admin account.
- Default administrator: username  admin   password  Admin@123  (must be changed at first login).

AUTOMATED TESTS (run before the demo)
- Run TreeYield.Tests (in Visual Studio: right-click the project > Debug > Start New Instance, or
  run Interactive Tree Database\TreeYield.Tests\bin\Debug\TreeYield.Tests.exe).
- Expected: "94 passed, 0 failed, 0 skipped."  The 94 tests cover the formulas, validation rules,
  password hashing, CSV escaping, SQL helpers, and 22 database tests on a throw-away .mdb file
  (SQL injection, validation rules, unique index, cascade delete, login lockout, password change,
  file opened exclusively by another program, reset data).
